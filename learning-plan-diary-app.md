3. **Работа с ASCII/Unicode**

   - Разница между ASCII и Unicode

4. **Обработка строк посимвольно**

### Неделя 5: Усложнённое шифрование и хеширование

#### Чему учить:

1. **XOR-шифрование**
   - Побитовая операция XOR (`^`)
   - Свойства XOR: `A ^ B ^ B = A`
   - Шифрование текста ключом
   - Почему XOR — основа многих шифров
   - Расширение ключа до длины текста

2. **Модуль `hashlib` — хеширование**
   - Чем хеширование отличается от шифрования
   - Односторонняя функция (нельзя расшифровать)
   - Алгоритмы: MD5, SHA-256
   - Создание хеша строки:
     ```python
     import hashlib
     hash_object = hashlib.sha256(password.encode())
     hash_hex = hash_object.hexdigest()
     ```
   - Проверка пароля по хешу
   - Зачем хранить хеш, а не пароль

3. **Соль (salt) для паролей**
   - Проблема: одинаковые пароли = одинаковые хеши
   - Генерация случайной соли
   - Формат хранения: `соль + хеш(соль + пароль)`
   - Проверка с использованием соли

4. **Модуль `secrets` для криптографии**
   - `secrets.token_hex()` — случайная строка
   - `secrets.choice()` — случайный выбор
   - Почему `secrets` лучше `random` для паролей

#### Практические задания:
- ✅ XOR-шифровальщик с текстовым ключом
- ✅ Система регистрации: сохранение логина и хеша пароля
- ✅ Система входа: проверка пароля по хешу
- ✅ Генератор случайных паролей

## 💡 Советы для родителей/наставников

1. **Будьте терпеливы** — ошибки — это нормально, они учат лучше любой теории
2. **Поощряйте эксперименты** — пусть пробует менять код и смотреть, что получится
3. **Не давайте готовых ответов** — направляйте вопросами: "Что произойдёт, если...?"
4. **Празднуйте победы** — каждая рабочая функция — повод похвалить
5. **Не торопите** — лучше медленно, но с пониманием
6. **Связывайте с реальностью** — "это как в настоящих программах, которые ты используешь"
